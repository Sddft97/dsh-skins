The skin center publishes on the family's aligned version. This release delegates Wallpaper Engine to its own plugin and yields the page to it, turns the skin grid into a wallpaper-style layout with preview thumbnails, adds seven skins, and fixes first-screen and multi-skin rendering on Windows.

> **Important change (please read)**: the skin center's built-in Wallpaper Engine bridge is removed. Mount `dsh-plugin-wallpaper-engine` (`dsh plugin --profile web add dsh-plugin-wallpaper-engine`) and it owns the wallpaper library, the renderer and the settings panel; the skin center only probes it read-only and yields the whole page while `body[data-we-wallpaper]` is present (no stylesheet, patches or hooks are injected, and the `html[data-dsh-skin]` stamp is removed). An activation the user already made is still recorded and repaints once the attribute clears. A retired `skin-wallpaper` section left in an existing profile passes through harmlessly, so an upgrade never breaks a profile over it. The package name `@linxin666/dsh-client-ui-skin-center` and its install path are unchanged: the npm package still ships only `blue-fantasy`, and every other skin stays market content installed on demand into `$DSH_HOME/skins/<id>/`.

- A wallpaper-style skin grid whose cards carry preview thumbnails
- A user-initiated activation claims the stage immediately instead of waiting for the next restart (#49)
