皮肤中心与皮肤集合迁出 dsh-web 主仓后的首次独立发布。包名 `@linxin666/dsh-client-ui-skin-center` 与安装方式不变，版本线从本版本起独立推进。

> **重要变更**：本版本没有需要手工迁移的改动，但相对 npm 上现存的 0.3.24 修复了一个会让插件无法激活的缺陷：此前发布的 0.3.24 仍然注入 0.1.7 已下线的 `settingsScope` 服务（构建产物里出现 7 处），在 0.1.7-rc.1 宿主上挂载会停在等待 `settingsScope`，永不激活。本版本随 0.1.7-rc.1 适配移除了该注入。npm 包仍然只内置 `blue-fantasy` 一套皮肤，其余 41 套皮肤由工坊按需从 `dsh-market.com` 下载到 `$DSH_HOME/skins/<id>/`；皮肤集合现在托管在本仓库的 `skins/`，提交新皮肤请直接向本仓库开 PR。

### 新功能

- 独立仓库：皮肤集合与皮肤中心单独维护，皮肤 PR 在本仓库单独合入
- 插件列表图标（`icon.svg`）

### 修复

- 移除已下线的 `settingsScope` 注入，恢复在 0.1.7-rc.1 宿主上的激活

### 其他改动

- 新增 CI（含 catalog、hooks 与已提交 `lib` 的一致性门禁）与 tag 触发的发布管线
- 补齐 CONTRIBUTING、皮肤 PR 模板与仓库元数据

<summary>English</summary>

First standalone release after the skin center and the skin collection moved out of the dsh-web monorepo. The package name `@linxin666/dsh-client-ui-skin-center` and the install path are unchanged; the version line advances on its own from here.

> **Important change**: no manual migration is needed, but this release fixes a defect that stopped the plugin from activating. The 0.3.24 currently on npm still injected the `settingsScope` service retired in 0.1.7 (7 occurrences in the built bundle), so mounting it on a 0.1.7-rc.1 host stalled waiting for that service and never activated. This release carries the 0.1.7-rc.1 adaptation that removes the inject. The npm package still bundles only the `blue-fantasy` skin; the other 41 skins install on demand from `dsh-market.com` into `$DSH_HOME/skins/<id>/`. The skin collection now lives in this repository under `skins/`, so submit a new skin as a pull request here.

### New Features

- Standalone repository: the skin collection and the skin center are maintained here, and skin pull requests merge here
- A listing icon for the plugin (`icon.svg`)

### Bug Fixes

- Drop the retired `settingsScope` inject and restore activation on a 0.1.7-rc.1 host

### Other Changes

- Add CI (catalog, hooks, and a committed-`lib` consistency gate) and a tag-triggered release pipeline
- Add CONTRIBUTING, the skin pull request template, and repository metadata
