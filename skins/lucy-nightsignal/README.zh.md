# 露西·夜城信号

[English](README.md) | 中文

银发彩虹渐变的夜之城网络黑客 · 双立绘天台背景 · 青洋红霓虹玻璃面板。纯资产皮肤目录，无 `package.json`、无构建步骤；皮肤中心是唯一加载器。

## 是什么

- `skin.json`（v2 清单）+ `skin.css`（L1 token 重映射，亮色 `:root` / 暗色 `body[data-ds-dark-theme]`）+ `patches.css`（L3：两层立绘与霓虹描边）。
- 亮色背景是白天云海之上的天台，暗色背景是霓虹夜之城；两侧立绘分别为背面与正面姿态。
- 立绘由本地色度键控从纯品红底抠出并去溢色，场景保持不透明。
